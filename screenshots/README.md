# Screenshots

Save genuine screenshots of your own lab run in this folder. PNG is recommended. Use the numbered naming scheme below to make the evidence easy to review.

- `01-user-created.png`
- `02-workspace-created.png`
- `03-files-and-listings.png`
- `04-permissions-640.png`
- `05-backup-recovery.png`
- `06-ownership-change.png`
- `07-final-tree.png`

## Screenshot quality checklist
- Show the command and its output clearly.
- Keep the terminal readable and avoid cropping the key evidence.
- Do not include passwords, tokens, private keys, or unrelated personal information.
- Do not use sample or fabricated screenshots as evidence of completion.
